\section*{Overview}

\begin{frame}{Overview}
    \emph{Goal}: Write programs to solve 2D mazes using Depth-First Search (DFS) and Breadth-First Search (BFS).

    Reinforces key Data Structures concepts:

    \begin{itemize}
      \item  Recursion
      \item  Stacks and Queues
      \item  Searching algorithms
      \item  Structs, pointers, and heap memory
    \end{itemize}

    Application links to Project 2 and upcoming Binary Search Trees and Graphs.
\end{frame}

\begin{frame}{DFS vs BFS Comparison }
  \begin{tabular}{r l l}
    \toprule
      \emph{Feature}	& \emph{DFS}	& \emph{BFS}\\
    \midrule
      Data Structure	& Stack (or recursion) &	Queue\\
      Search Style	& Deep	& Broad\\
      Finds Shortest Path? & No & Yes\\
      Overall Memory Usage	& Lower	& Higher\\
      Implementation	& Often recursive	& Iterative\\
      Backtracking	& Implicit	& Not needed\\
    \bottomrule
  \end{tabular}
\end{frame}
